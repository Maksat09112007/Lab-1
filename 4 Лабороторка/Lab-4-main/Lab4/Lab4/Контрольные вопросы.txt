1. Что такое HTML-форма?
Это блок страницы, заданный тегом <form>, внутри которого находятся элементы для ввода данных (поля, списки, флажки, кнопки). Форма собирает данные пользователя и отправляет их на сервер или передаёт на обработку в JavaScript.

2. Для чего используются элементы input, select и button?
<input> создаёт поле ввода: текст, e-mail, число, checkbox, radio и другие типы, в зависимости от атрибута type. <select> создаёт выпадающий список, из которого выбирают один вариант (или несколько). <button> создаёт кнопку, например кнопку отправки формы.

3. Чем checkbox отличается от radio?
Checkbox позволяет выбрать любое количество вариантов из группы, включая ни одного, и каждый флажок можно снять. Radio-кнопки с одинаковым name образуют группу, в которой можно выбрать только один вариант, и выбор снимается только выбором другой кнопки.

4. Что такое клиентская валидация?
Это проверка введённых данных в браузере пользователя до отправки на сервер: на пустые значения, длину, диапазон чисел, формат e-mail, обязательный выбор. Она сразу показывает пользователю ошибки и делает интерфейс удобнее.

5. Для чего используется событие submit?
Оно возникает при отправке формы (нажатие кнопки submit или Enter в поле). На него вешают обработчик, чтобы проверить данные и решить, отправлять форму или нет.

6. Что делает event.preventDefault()?
Отменяет стандартное поведение браузера для события. В случае submit это значит, что страница не перезагружается и форма не отправляется на сервер, поэтому данные можно проверить и обработать в JavaScript.

7. Как получить значение текстового поля в JavaScript?
Через свойство value элемента: document.getElementById('name').value. Обычно добавляют .trim(), чтобы убрать пробелы по краям: document.getElementById('name').value.trim().

8. Как проверить состояние checkbox?
Через свойство checked: document.getElementById('agree').checked возвращает true, если флажок отмечен, и false, если нет.

9. Как получить выбранное значение select?
Через свойство value элемента <select>: document.getElementById('course').value. Оно возвращает значение value выбранного <option>. Если ничего не выбрано, вернётся пустая строка (для варианта «Выберите курс» с value="").

10. Почему клиентская валидация не заменяет серверную?
Код в браузере находится под контролем пользователя: его можно отключить, изменить через инструменты разработчика или вообще обойти, отправив запрос напрямую. Поэтому клиентская проверка нужна только для удобства, а безопасность и корректность данных обязательно должен проверять сервер.
